01 / همهٔ برنامه‌ها

چیزی برای کشف کردن.

فهرست زندهٔ برنامه‌های مخزن Lumen. روی هر برنامه بزنید تا جزئیات و دانلود APK را ببینید.

برنامه‌های فهرست Lumen پس از بررسی و تأیید مدیریت منتشر می‌شوند و فایل APK مستقیم از بخش Releases مخزن GitHub هر پروژه دریافت می‌شود. فهرست هر ساعت به‌روز می‌شود. مخزن رسمی فهرست: deepcodecreate/lumenrepo

02 / برای سازندگان

اپتان را در Lumen Store ثبت کنید.

ابتدا شرایط پذیرش را بخوانید، سپس فرم را پر کنید. درخواست شما در تلگرام بررسی می‌شود.

شرایط پذیرش برنامه در Lumen Store

  1. برنامه باید متن‌باز باشد و سورس‌کد آن در یک مخزن عمومی GitHub منتشر شده باشد.
  2. مخزن باید شامل آیکون رسمی برنامه با فرمت PNG و تصاویر اسکرین‌شات باشد.
  3. اسکرین‌شات‌ها باید عمودی و با نسبت تصویر ۹:۱۶ باشند.
  4. آیکون‌های فاقد پس‌زمینه مناسب (Transparent) و لوگوهای نامتقارن یا غیراستاندارد پذیرفته نمی‌شوند.
  5. مدیریت دسته‌بندی‌ها و تگ‌های برنامه باید اصولی، دقیق و متناسب با عملکرد واقعی آن باشد.
  6. توسعه‌دهنده باید لینک مخزن GitHub و شناسه بسته (Package Name) را برای بررسی ارسال کند.
  7. تمامی برنامه‌ها پیش از انتشار، از نظر کیفیت، صحت اطلاعات، امنیت و سلامت فایل‌های اجرایی بررسی و آزمایش خواهند شد.
  8. انتشار برنامه در Lumen Store منوط به تأیید نهایی مدیریت فروشگاه است.
  9. Lumen Store از به‌روزرسانی خودکار اطلاعات نسخه‌ها بر اساس Release و Tag مخزن پشتیبانی می‌کند؛ بنابراین پس از ثبت و تأیید اولیه، برای انتشار نسخه‌های جدید نیازی به ثبت مجدد برنامه نیست.
  1. شرایط پذیرش را بخوانید و مطمئن شوید مخزن شما آن‌ها را دارد.
  2. فرم را پر کنید؛ نام برنامه، شناسهٔ بسته و پیوند مخزن GitHub الزامی است.
  3. دکمهٔ «ارسال در تلگرام» پیام آماده را کپی می‌کند و گفت‌وگو با من را باز می‌کند؛ پیام را Paste کنید.
  4. پس از بررسی و تأیید نهایی، برنامه به فهرست Lumen اضافه می‌شود.
پیام در تلگرام @lsolbl قوانین و شرایط پذیرش lumenrepo کانال اطلاع‌رسانی @deepcodecreate

پیام آماده در کادر زیر دیده می‌شود. اگر تلگرام باز نشد، همان را کپی و برای @lsolbl بفرستید.
